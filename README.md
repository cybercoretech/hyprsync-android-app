# hyprsync-android-app 🚀

## Project Overview
HyprSync is an Android app that lets users quickly share encrypted contact information via QR codes. It uses **SQLCipher** for on‑device encryption, **Room** for a clean data layer, and **Kotlin** + **Jetpack Compose** for the UI.

## Timeline & Milestones
- **2026‑10‑01** – Project kickoff, core architecture design.
- **2026‑10‑15** – QR‑Share screen wired to encrypted SQLite DB.

- **2026‑11‑12** – First beta release on Play Store (internal testing).
