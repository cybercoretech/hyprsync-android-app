# AGENT_HANDOFF.md

## Purpose
This document defines how the Antigravity agents will hand off work to the developer and external systems throughout the lifecycle of the **HyprSync** Android Personal CRM project.

## Handoff Flow
1. **Scaffolding & Initial Setup** – The `self` agent creates the project structure, adds required Gradle files, and writes the initial `AGENTS.md` and `AGENT_HANDOFF.md` files.
2. **Branding Confirmation** – The agent includes a clear branding note (see `AGENTS.md`) to differentiate from the Hyprland sync daemon.
3. **Feature Planning** – For each feature, the agent produces a **plan** (markdown) and requests user approval before any code changes.
4. **Implementation** – After approval, the agent generates code snippets or shell commands. All modifications are presented to the user for final confirmation.
5. **Testing & Verification** – The agent runs unit/instrumented tests, reports results, and asks the user to verify before merging.
6. **Release Preparation** – The agent creates a release‑ready build, updates versioning, and adds a note to the personal notes file.
7. **F‑Droid Publishing** – The agent drafts a GitHub Actions workflow for F‑Droid, but does **not** push it until the user explicitly triggers it.

## Communication Channels
- **User** – All decisions, approvals, and final merges require explicit user confirmation.
- **GitHub** – The repository `https://github.com/cybercoretech/hyprsync-android-app` will hold the source and CI configuration.
- **Personal Notes** – Summary of each major milestone is appended to `/home/raven/Notes/hyprsync_notes.md`.

## Branding Note
> **HyprSync** is **not** related to the existing Hyprland configuration‑sync daemon (`github.com/Hyprland/HyprSync`). The branding explicitly states: *"HyprSync – Personal CRM for Android"* to avoid confusion.
